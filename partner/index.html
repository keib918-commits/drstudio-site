발송 대기 주문

    라벨은 주문 접수와 동시에 발급됩니다. 포장 뒤 '라벨' 버튼으로 출력하고, 택배 운송장 번호를 입력하면 발송 완료로 바뀝니다.

    최근 7일 주문

    재고 알림

      주문

      귀사 상품의 주문만 보입니다. 구매자 정보는 라벨에 필요한 범위만 표시합니다.

      주문번호주문 시각상품 · 수량판매가구매자 · 도시발송 기한상태처리
      상태 흐름: 발송 대기 → 발송 완료(운송장 입력) → 김포 집하지 스캔 → 배송 중 → 배송 완료 → 구매 확정(정산 반영). 취소·환불 주문은 정산에서 제외됩니다.

      재고

      가용 수량을 입력하면 저희 쇼피 리스팅 재고에 동기화됩니다. 0이 되면 리스팅이 자동으로 품절 처리되어 주문 취소가 생기지 않습니다.

      SKU상품판매가공급가가용 수량리스팅 상태마지막 동기화
      공급가는 판매가 기준 귀사 몫(약 45%)을 ₱1 ≈ ₩22로 환산한 예시입니다. 실제 공급가와 환율 기준은 계약서로 정합니다.

      정산

      매월 말 마감, 익월 10일 정산서 발행, 귀사 세금계산서 수령 뒤 익월 20일 지급. 구매 확정 주문만 반영합니다.

      SKU상품구매 확정 수량판매가 합계쇼피 공제닥터서울 몫귀사 공급가 ₱귀사 공급가 ₩
      주문번호 단위 명세는 정산서에 포함됩니다. 이의 제기 기간 7영업일.

      발송 가이드

      주문이 오면 이 여섯 가지만 지키시면 됩니다.

      1
      주문 알림
      • 화면과 이메일로 즉시 알림
      • 라벨은 자동 발급, 주문 화면에서 내려받기
      2
      포장
      • 1주문 1포장, 합포장 금지
      • 상자 + 에어캡 2~3회 + 빈 공간 채움 + H테이핑
      • 제품 외관·유통기한 확인
      3
      라벨 부착
      • A6 또는 A4에 출력해 상자 윗면에 부착
      • 바코드가 접히거나 테이프에 가리지 않게
      4
      국내 택배 발송
      • 받는 곳: 쇼피 김포 집하지(주소는 계약 후 안내)
      • 택배비는 귀사 부담, 평소 쓰시는 택배사 가능
      5
      운송장 입력
      • 주문 화면에 택배 운송장 번호 입력
      • 이후 김포 스캔·국제 배송은 저희가 추적
      6
      기한과 품절
      • 주문 다음 영업일 오후 4시 집하까지 발송
      • 수요일 주문과 연휴 전후는 당일 발송 권장
      • 재고가 줄면 재고 화면에서 수량 갱신
